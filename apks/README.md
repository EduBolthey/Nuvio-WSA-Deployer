# APKs Directory

Place your custom or release `.apk` files here (e.g. `Nuvio-Debug.apk` or `NuvioMobile-Enhanced.apk`).

The automated installer will:
1. Scan this directory for any `.apk` file.
2. Automatically select the newest package.
3. Sideload it into Windows Subsystem for Android with all runtime permissions auto-granted.

If this folder is left empty, the installer will automatically download the latest build from the GitHub Releases section.
